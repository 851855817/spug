# 宝塔批量面板任务使用说明

运行镜像、部署时间和验证证据见 [部署记录](../deploy/baota/DEPLOYMENT-PANEL-TASKS.md)。本文描述当前源码支持的功能。

地址：<http://127.0.0.1:18080/>（本机 SSH 通道连接服务器）。入口：Spug 左侧 **批量执行 → 面板任务**。

## 先配置面板 API

在“宝塔面板管理 → 添加面板”或已有记录的“编辑”中，向下滚动到 **API 连接（选填）**，即可与登录信息一起保存 API 基础地址和 API 密钥。暂时只管理登录入口时可不填；之后仍可编辑补充。创建面板任务会自动使用已保存配置，无需再次填写 API 信息。

API 密钥与网页登录密码不同；在客户宝塔设置中开启 API，并把 Spug 的实际出口 IP 加入 API 白名单。新增记录保存后，在列表点击“测试连接”。已有密钥加密保存，编辑留空保留原值。

登录地址可保留宝塔安全入口；API 基础地址默认自动从登录地址提取协议、主机和端口，去掉安全入口、查询和片段，无需重复输入。例如 `https://panel.example:8888/entry` 会自动填为 `https://panel.example:8888`。反向代理含路径前缀时可手动修改；已有保存的地址和手动修改后的值不会跟随登录地址变化。历史未配置 API 的记录，普通编辑未填密钥时仍保持 API 未配置。

HTTPS 使用系统证书验证，也可为自签证书配置专用 CA 或核对并固定证书 SHA-256 指纹。保存后执行连接测试。

本版适配宝塔 Linux **9.2.0、11.7.0、13.1.0**。未配置、未测试或不支持的面板会显示原因。9.2 不再被统一版本门禁阻挡，但各操作仍会核对实际资源、依赖和协议。已有失败的历史任务不会自动变为可执行，需要新建预检。

9.2 面板升级需明确选择官方稳定通道。旧接口无法锁定最终版本，预检显示当前候选并在执行前单独确认；版本或候选漂移会阻止下发，实际升级偏离候选则保留待核实。SSL 增加标准 Nginx／Apache 主配置与固定公开证书核验，自定义证书路径或未适配配置会阻挡。适配依据见 [升级](research/2026-10-22-upgrade92.md)、[SSL](research/2026-10-22-ssl92.md)；[初次审计](research/2026-10-22-baota-9.2-audit.md)保留为变更前记录。

“只读预检”表示 Spug 不下发选定的升级、安装或网站配置变更请求，不能承诺宝塔内部零写盘。官方的部分查询接口会触发缓存更新、证书入库、配置初始化，软件目录查询还可能启动维护脚本。本次源码审查发现的跨版本边界与未解决项已在上述报告列明；未将源码分支视作客户面板已经发生的事件。

## 发布批量任务

1. 选择面板或分组。分组包括子分组，重复面板自动去重。
2. 选择操作，展开各面板，读取该面板自己的网站、软件、版本或扩展选项并填写参数。建站支持结构化表格和批量粘贴；每行需对应目标面板。
3. 点击“生成冻结预检”。此时仅检查和保存计划，不会授权变更。
4. 核对每台面板、每个网站或扩展的当前状态、拟执行动作和影响范围，完成要求的确认后，点击“确认并开始执行”。
5. 在执行记录中查看结果。关闭网页不影响后台执行。

一次最多选择 50 个面板、处理 200 个子项目；最多并行两个面板，同一面板的变更串行。网站 ID、软件版本均按各自面板处理，不能在不同面板间借用。

## 九类操作

| 操作 | 填写或选择 |
|---|---|
| 面板升级 | 9.2 选官方稳定通道；较新版本选已适配的官方目标版本 |
| 更新 PHP（同分支） | 选择已安装且有更新的分支，显示实际 CLI 当前版本与预计补丁目标 |
| 添加网站 | 目标面板、域名、目录、端口、已安装 PHP 或纯静态 |
| 防跨站 | 各面板的网站或本次全部网站，开启／关闭 |
| 伪静态 | Nginx／Apache、自定义／模板／清空，以及网站 |
| SSL 证书 | 申请／续签、网站与域名；使用 HTTP 文件验证 |
| 安装软件 | 当前客户宝塔软件商店中的名称、已装状态、版本和安装方式；目前开放官方免费异步核心软件 |
| 安装 PHP 扩展 | 已安装 PHP 分支及该分支支持的扩展 |
| 卸载软件 | 已安装软件及预检列出的依赖影响 |

安装软件不会隐含升级已有软件或切换网站 PHP 版本。完整官方 API 目录可搜索，但“目录收录”不表示已接入执行。

PHP 更新通过官方编译脚本在同一分支内更新，不改变网站绑定。例如 PHP 7.4 的更新仍为 7.4.x。预检列出使用该分支的网站，执行前确认可能重启 PHP 并短暂影响网站；补丁由官方在线脚本决定，不能锁定。只有唯一关联队列结束、安装目录身份未变且实际 CLI 版本精确匹配预期，才报告成功；这不代表已经验证 FPM 服务健康。未知、偏离或并发冲突均保留待核实，详见 [PHP 更新依据](research/2026-10-22-php-update.md)。

## 如何处理结果

- “已结束”表示流程结束，需同时查看成功、失败、已符合、跳过与待核实数量。
- 软件入队、证书订单 pending、面板提示已启动，都不作为最终成功依据。
- 伪静态文件保存后，官方接口无法证明 Web 服务成功加载时，会保留“待核实”及面板锁。管理员核对实际加载情况后，再填写结论、原因和核验依据。
- “只读核验”用于查询状态，不会重发变更。请求可能已送达却未收到响应时，系统保留锁并阻止盲目重试。
- “取消未下发项”只取消尚未发送的项目；已经进入宝塔的操作可能继续运行。
- “关联新预检重试”创建新任务，仍需独立检查与确认。原来缺少参数的面板在连接恢复后，应重新填写表单生成预检。

SSL 申请／续签可能自动同步同一面板内符合条件的同域名证书，包括未选网站、孤立副本和面板自身 TLS，并可能重载 Web 服务。预览中的登记网站清单不完整，不能作为同步范围白名单。开始前需明确确认此影响。结果核对所选网站的证书配置，不等于验证了实际 TLS 握手或所有自动同步位置。

## 权限与记录

角色管理中可分别分配任务查看、创建、执行、取消和管理权限。普通用户查看自己的任务；管理权限可查看全部并处理待核实项目，但不会单独授予执行权限。现有面板分组用于组织和选择，不提供客户租户隔离。
