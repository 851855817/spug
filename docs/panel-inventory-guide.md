# 网站证书与备份检查台

这两个入口位于“批量执行”，仅超级管理员可用。目标来自“宝塔面板管理”，沿用每个面板已保存的 API 配置；无需再次输入 API 密钥。查看、筛选、翻页和“刷新缓存”只读取 Spug 已保存的数据，首次打开不会联系客户面板，也不会自动开始周期采集。

## 网站与证书

入口：**批量执行 → 网站与证书**。

按服务器或分组查找网站，查看域名、PHP 分支、站点状态，以及面板登记的证书到期日。证书分为“有效”“30 天内到期”“已到期”“未配置”“未知”。例如：筛选“30 天内到期”，集中安排本周的续签工作；筛选“未配置”，查找尚未登记 SSL 的网站。

上方统计项可直接点击：选择某个证书状态或“旧缓存”，列表立即显示符合条件的网站，并同步状态选择框、突出当前选项；零条也可点击。点击“范围内总计”恢复当前范围全部网站。切换时保留分组、服务器和关键词，从第一页显示；统计数量始终代表状态筛选前的当前范围，不会因选中某个状态而把其他计数清零。筛选只读取缓存，不主动采集。

剩余天数按平台日期（当前为 UTC+8）计算：到期当天显示 0 天，次日显示已到期；第 30 天属于临期，第 31 天属于有效。读取缓存时会重新计算日期，无需重新采集，但这不会更新面板登记内容。这里仅有到期日期，无法判断当天的精确失效时刻；当天需用实际证书核实，不能据此认为全天有效。

“填写申请任务／填写续签任务”会打开原有“面板任务”，预填面板、网站和操作选择。入口不会自动查询资源、生成预检或执行申请。请在任务表单核对网站、域名及验证方式，再按原流程预检和确认执行。

此处是**面板登记摘要**，未验证域名解析、公网 TLS 握手、源站或 CDN 实际使用的证书。未知状态不能当作未配置，旧缓存也不能证明当前证书仍有效。

## 备份检查台

入口：**批量执行 → 备份检查台**。

按面板查看每个网站和面板登记的 MySQL 数据库的最近一条备份，显示登记时间、文件大小、面板报告的本地文件存在状态及是否仍在进行。其他数据库类型暂未覆盖。可选 24、48、72 或 168 小时的逾期阈值，默认 48 小时；例如筛选“超过阈值”，发现可能漏跑的备份计划。

统计项与网站页使用相同的点击筛选规则；点击“超过阈值”沿用当前小时数，点击“旧缓存”按缓存状态筛选，点击总计只清除状态筛选。

| 状态 | 如何理解 |
| --- | --- |
| 无记录 | 面板未返回该资源的备份登记，不代表磁盘上没有手工备份 |
| 本地文件缺失 | 面板报告本地文件不存在；若为云端记录，不代表云端对象丢失 |
| 空文件 | 面板报告本地存在，但登记大小为零，需人工核对 |
| 进行中 | 面板报告备份尚在进行，稍后重新采集确认 |
| 面板报告存在 | 面板报告本地存在且大小非零；不代表归档完整、可解压或可恢复 |
| 未知 | 面板未给出足够的可信字段，需人工核对 |

云端记录仅表明面板登记过云备份，不会联系云服务商验证对象。页面不读取云凭据、不下载或解压备份，也不提供备份、删除或恢复操作。面板备份时间通常没有时区，平台按自身时区估算年龄；远端时区和时钟未核实，未来时间显示年龄未知。

## 主动采集与缓存

1. 在宝塔面板管理中保存并测试 API 配置。
2. 在上述页面选择面板，或按服务器／分组限定范围，再点击“采集所选面板”“采集当前范围”或“采集全部面板”。关键字和资源状态只筛选缓存，不改变采集面板范围。
3. 查看下方“各面板采集状态”。没有资源、未配置、尚未采集和失败的面板也会显示在这里。
4. “停止后续采集”、隐藏标签或离开页面会停止后续面板；已经发出的请求继续受后端总时限约束，不能视为撤回。

两个页面及多个浏览器共用一个采集槽，按面板顺序读取；另一轮占用时提示忙碌。单面板总时限 45 秒，单种类冷却 30 秒；最多 200 次 API 请求、1,000 项资源、5,000 条域名。超过限制会失败并保留上次成功快照，不把截断结果当作完整总览。大量资源可能需要后续扩展增量采集。

失败保留上次成功数据并标为旧缓存，同时显示上次成功和最近尝试时间；超过 24 小时也标为旧缓存。API 地址、密钥或信任配置变化后，旧资源不再列出，需重新采集。修改过期阈值只重新计算缓存，不访问面板。

当前读取协议按 Linux 面板 9.2.0、11.7.0、13.1.0 的固定源码核对；其他版本会拒绝采集，需先适配。API 元数据查询在面板内部可能更新分页／排序缓存、初始化网站配置或清理过时的备份 `.pl` 标记；本功能不发送升级、配置修改、恢复或删除命令，但不承诺面板内部零写盘。协议依据见 [协议审查记录](research/2026-10-24-inventory-protocol.md)。

## 巡检结果

入口：**批量执行 → 运维作业 → 执行记录 → 查看结果**。列表显示主机、正常／异常／待核实、异常原因及检查数据；使用状态筛选缩小范围，点击“查看数据”展开指标与已有告警解释。

创建或打开记录后会定位到结果区域，地址中的 `run_id` 支持刷新恢复到同一作业。查看结果和刷新不会重新执行；本版不随浏览器前进／后退动态切换作业。完整作业、基线与分批规则见 [运维作业指南](operations-center-guide.md)。
