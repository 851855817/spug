# 账号资源权限与服务器额度

本功能已于 2026-11-06 发布至公网服务，应用版本 `15d69ee`。管理员从“系统管理 → 账户管理”设置服务器额度和资源分配；逐项操作权限在“角色管理”设置。

## 管理员怎样授权

给员工设置岗位角色、服务器总额度和具体资源授权。三个条件共同生效：账号处于启用状态、岗位允许对应操作、服务器属于本人或已明确分配。

1. 在“系统管理 → 角色管理”勾选岗位需要的具体动作；可套用五个岗位模板，再按实际工作调整并保存。
2. 在“系统管理 → 账户管理”新建或编辑普通账号，选择岗位角色。
3. 在“服务器额度与资源分配”填写服务器上限。只允许自行添加时，无需分配已有资源；需要交接服务器时，把对应记录设为“只读”或“可管理”。
4. 保存后重新打开账号，展开“当前已保存策略的最终生效预览”，核对功能、本人／管理员分配的资源及已用额度。草稿修改需保存后才生效。

已有角色不会被自动替换或增加高风险权限。主机连接验证、宝塔测试连接、一键登录、SSH、续签和升级等各自授权；只勾选页面查看不能执行这些动作。

例如 A 的额度为 5，具有主机添加、监控查看和巡检权限。A 添加 2 台 SSH 主机与 2 个宝塔面板，其中一对由管理员确认关联，实际占用为 3 / 5。再添加 2 台后额度用完。添加、导入和管理员分配都必须遵守此额度。

新普通账号默认额度为 0。额度可以是非负整数；“不限”必须由管理员明确设置。调低额度不会删除已有服务器，也不会自行收回其权限；增加净占用的操作会被拒绝。管理员不受额度限制。

## 只读、管理和岗位权限

“只读”允许查看该服务器的数据，但不能因为岗位包含执行权限就升级为可操作。“管理”允许使用该服务器，但仍受岗位逐项权限限制。

| 需求 | 岗位需要的权限 | 资源要求 |
| --- | --- | --- |
| 查看监控、证书和到期数据 | 对应页面查看 | 本人或只读／管理授权 |
| 开关监控、主动采集 | 对应配置／采集 | 本人或管理授权 |
| 登录宝塔 | 宝塔一键登录 | 面板管理授权 |
| 打开 SSH、上传或删除远程文件 | 对应终端／文件动作 | 主机管理授权 |
| 升级 PHP、宝塔或安装软件 | 创建／执行面板任务及对应动作 | 全部目标面板管理授权 |
| 申请或续签 SSL | SSL 续签与相应面板动作 | 对应来源及目标管理授权 |
| 启用、手动运行计划 | 计划启用／运行及任务动作 | 全部目标管理授权 |

多个角色的功能权限合并，但不会自动共享其他员工的服务器。相同 IP 不会自动关联，也不会自动授予另一侧的 SSH、宝塔或凭据访问权限。服务器到期的“负责人”用于跟进，与服务器归属不同。

普通账号可维护自己的分组；对获分配的服务器，即使授予“可管理”，也不能改动其归属组。编辑时保留原组。资源迁组由所有者或管理员处理，SSH↔宝塔关联仅由管理员确认，两者都需要相应功能权限。

## 哪些页面使用同一范围

主机、宝塔、首页、服务器监控、SSL、网站与软件库存、运维任务、任务计划、到期管理、提醒、导出和结果流统一按账号范围展示。应用发布保留原应用／环境权限，还需具有其中所有服务器的权限。

普通账号只能查看本人创建且全部目标仍有权的任务。混有失权目标的旧历史整体隐藏，防止总体摘要或日志包含其他服务器信息。管理员保留全局审计能力。

任务排队后仍会重新校验。禁用账号、撤销岗位动作或把管理授权改为只读，会阻止后续未下发动作并保存结束状态；已发送的远程操作不能据此撤销。已经打开的终端和输出流也会重新检查授权。

旧式 URL、端口和 Ping 检查保留自建外部服务监控能力，按监控项创建者隔离；使用平台主机记录的进程／脚本检查则额外校验全部主机管理范围。

## 常见情况

- 提示额度不足：请管理员增加额度，或收回已不需要的资源。关闭监控、隐藏证书不会释放额度。
- 能看不能执行：检查是否仅有只读授权，以及岗位是否勾选了对应动作。
- SSH 要求独立密钥：普通账号新增主机使用自己的连接凭据。旧普通创建者且未保存独立密钥的记录不会自动借用平台全局私钥。
- 关联解除失败：解除关联可能让原来计为一台的多个连接占用更多额度，需要先调整受影响账号额度。
- 任务突然停止：检查账号状态、岗位动作、管理授权及任务创建后目标／API 配置是否变化，修正后重新发起。
