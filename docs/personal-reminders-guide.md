# 个人提醒设置

首页待办、右上角通知和「主机管理 → 到期管理 → 站内提醒」每条信息后提供 **不再提醒**。点击保存成功后，该条从当前账号的提醒中隐藏，其他账号照常看到。

- 证书与服务器：只忽略这次到期日期。续期后日期变化，会重新提醒。
- 事务通知：只忽略这条消息；相同内容的新消息仍会提醒。
- 任一提醒区域的 **已忽略（N）** 可查看全部个人忽略项，点击 **恢复提醒** 即可重新显示。

设置保存在服务器，刷新页面或换浏览器登录同一账号后仍有效。隐藏不删除资产、任务或历史记录，不修改其他人的阅读状态。首页分类数量和到期管理的原始总数仍保留，便于查看实际资产情况。

**批量执行 → 网站与证书** 也可在临期／已过期证书的“证书任务 / 提醒”列选择“不再提醒”，与首页同一证书同步。这里保留网站行、续签入口及真实统计，已忽略的可直接恢复；顶部也有“已忽略”入口。

读取设置失败时会显示错误与重试入口；保存失败时原提醒保留。缺少有效身份或到期日期的事项不能误屏蔽。这里的“不再提醒”用于具体待办与通知，不会关闭监控、全局提醒或掩盖采集数据不完整等系统提示。
