# 隐藏批量执行的网站与证书入口

用户明确要求移除“批量执行 → 网站与证书”，证书功能已有“监控中心 → SSL监控”。按当前菜单精简机制，为 `/exec/sites` 路由设置 `hidden: true`；不删除页面或后台接口，首页待办和历史书签继续兼容。导航排序及恢复默认均不能重新显示隐藏项。监控中心的 `/monitor/ssl` 继续显示。

运行改动仅 `spug_web/src/routes.js`。无 API、权限、监控开关或数据库变更，不发起客户采集或证书操作。以浏览器模拟接口验证入口隐藏、SSL 入口存在、旧链接可打开。

沿用现有分支与草稿 PR。新增 routes 单文件 UI 发布范围，完整保全 API 树，最终候选验证使用 post-ssl；重新核对实际版本、空闲及 SSL 业务摘要，配对备份后发布。禁止复用上一轮基线或覆盖 API。
