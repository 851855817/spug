# 宝塔批量“执行面板任务”：第一版设计

日期：2026-10-22。状态：根据用户指定的八类操作修订，供实现前审查；新任务功能尚未编码或部署。

## 目标与方案

在现有 Spug 的“批量执行”中新增“执行面板任务”，对已添加的宝塔 Linux 面板或分组一次性下发操作，并保留每台面板、每个网站的实际结果。

第一版范围：宝塔面板升级、添加网站、配置防跨站、配置伪静态、申请或续签 SSL 证书、安装软件、安装 PHP 扩展、卸载软件。

推荐“宝塔 API + 按版本适配的操作表单 + 持久任务队列”。用户选择业务操作和参数，后台完成签名、版本检查、下发、监控和结果验证。

另外两种方式是 API 配合 SSH 脚本，或提供通用 API/命令编辑器。前者需要额外维护服务器凭据和系统脚本；后者需要用户自己判断接口参数和执行结果。第一版采用推荐方案，软件操作使用已核对的宝塔程序接口。

## 八类操作与验收

| 操作 | 页面参数及行为 | 成功判断 |
|---|---|---|
| 宝塔面板升级 | 选择面板官方提供的正式版本，显示每台当前版本和目标版本；升级时允许短暂断连 | 面板恢复连接，实际版本与目标相符；仅收到“已启动”不算成功 |
| 添加网站 | PHP 或纯静态站点；每条记录填写目标面板、主域名、附加域名、目录、端口及已安装 PHP 版本；可批量粘贴映射表 | 读回网站、域名、目录和 PHP 类型；域名冲突时给出逐条原因 |
| 配置防跨站 | 从每台面板读取网站，选择开启或关闭 PHP open_basedir；支持多个网站及“本次全部网站” | 逐网站读回开关状态；已符合目标的记录显示“已符合” |
| 配置伪静态 | 面板模板或自定义规则；按 Nginx/Apache 区分内容；展示将覆盖的当前规则 | 文件读回一致只证明保存。官方接口未确认 Web 重载，当前返回“配置已保存，Web服务加载结果需核实”，不自动报成功 |
| 申请或续签 SSL | 选择网站、域名及申请/续签；第一版使用免费的 Let's Encrypt，默认 HTTP 文件验证；续签使用网站关联订单；明确确认面板范围的同 SAN 证书自动同步 | 读回选定网站公开证书配置的域名、有效期和指纹；pending 不算成功，实际 TLS 连接及其他自动同步位置未核验 |
| 安装软件 | 从目标面板的软件商店获取软件、版本和安装方式；展示资源条件、互斥与依赖 | 远端任务完成后，软件实际已安装且版本相符；已安装同版本显示“已符合” |
| 安装 PHP 扩展 | 选择已安装 PHP 分支及该分支支持的扩展，可一次选多个，如 PHP 7.4 + redis、fileinfo | 逐扩展验证安装与加载状态，标明 PHP 分支；不能只检查全局文件存在 |
| 卸载软件 | 从每台已安装的软件选择；展示网站/数据库依赖及影响，保留宝塔自身的依赖和卸载限制 | 读回软件已卸载；无法判定请求是否执行时显示“待核实” |

建站第一版聚焦网站本身，FTP/数据库联建和代码上传不作为隐含动作。SSL 处理现有网站的单次申请与续签，不购买商业证书；泛域名及 DNS 自动验证留作后续扩展。软件范围以目标面板实际提供且适配通过的软件为准，付费插件仍需该面板已有授权。

SSL 的第一请求不是纯签发：官方 11.7.0/13.1.0 会自动替换本面板内符合签发者、SAN 集合及有效期条件的证书，涉及未选择网站、孤立证书目录，甚至面板自身 TLS，并重载 Web 服务；续签还可能临时切换 HTTP 跳转 HTTPS 配置。预检必须展示固定范围政策 `baota_acme_panel_sync_v1` 并要求 `ssl_panel_sync` 确认。已登记网站的公开证书清单最多扫描 200 个，始终注明不完整；不能把清单当成操作范围白名单。初次下发前复核已知清单漂移，任务服务持久化确认和涵盖自动同步的意图后才可调用适配器。若目标网站已自动更新则无需额外部署；需要 SetCertToSite 时仍单独持久化意图。固定 TLS 指纹变化导致连接失败时保留待核实和面板锁，由管理员核验信任，不自动换指纹。

原先方案中的服务启停、网站 PHP 切换不列入这次八类操作。安装、更新和切换版本不能混用：“安装软件”不会暗中更新已有软件或切换网站的 PHP 分支；软件升级不作为这次八类清单之外的隐含功能。

## 页面流程

入口：`批量执行 → 执行面板任务`。沿用现有 Spug 风格，提供新建任务、执行记录和可搜索的官方接口目录。

1. **选择面板**：按分组、子分组或面板多选，去重后固定本次目标。
2. **选择操作与对象**：按八类操作填写表单。网站配置可分别选择每台的网站，或选择“本次全部网站”；软件版本按目标面板展示兼容性。
3. **目标映射**：建站使用“面板 → 域名、目录、版本”表格，可批量粘贴；网站配置使用“面板 → 网站”表格。面板之间不共用网站 ID。允许显式选择多个面板使用同一域名，但不默认复制域名。
4. **预检与预览**：显示实际面板、网站、当前状态、拟执行动作及不可执行原因。“全部网站”在此展开为固定清单，后来新增网站不会自动纳入本次任务。
5. **开始执行**：用户在完整预览页提交。升级、覆盖规则和卸载显示具体影响，不能只展示笼统的服务器数量。
6. **查看结果**：查看汇总及逐面板、网站、扩展结果。页面关闭不影响执行。失败目标重新预检后发起关联的新任务。

完整官方接口目录用于分类、搜索和查看来源；八类之外的记录显示“目录收录，未接入”。目录存在不等于能执行，不提供任意 API 路径透传入口。

## 面板 API 接入

在“宝塔面板管理”增加 API 地址、API 密钥、HTTPS 信任配置、连接测试及探测到的面板版本。

- 保留登录地址、账户和密码。API 密钥独立于网页登录密码，需要在宝塔设置里开启 API，将 Spug 实际出口 IP 加入白名单。
- API 地址和登录安全入口分别保存，不将 API 请求拼到安全入口之后。API 基础地址只允许 HTTP/HTTPS，禁止嵌入用户名、密码、查询参数或片段；反向代理前缀以经过连接测试的配置为准。
- API 密钥沿用服务器持久密钥加密；仅返回“已配置”状态，编辑留空保留已有密钥。修改 API 地址后必须重新连接测试。
- HTTPS 默认使用系统证书验证；自签证书可为该面板配置可信 CA，或在展示证书后显式固定其 SHA-256 指纹。固定指纹只信任该面板的指定证书，证书更换后需重新确认，不全局关闭校验。HTTP 地址在表单明确显示为明文连接。
- 签名请求不跟随重定向；设置连接/读取超时及响应大小限制。地址、TLS、白名单/密钥错误分别显示，认证失败不连续重试造成面板封禁。

## 后台执行与状态

增加面板 API 客户端、按版本选择的操作适配器、任务记录、逐对象执行记录和独立后台进程，复用 Spug 登录、数据库、角色和镜像部署。

- 一次任务执行一种操作，可包含多个面板和多个网站/扩展子项。保存参数及目标快照，敏感字段不进入快照。
- 默认并行处理两个面板；同一面板的变更串行。远端共享日志时必须确认目标关联，不将其他操作者启动的任务认成本次结果。
- 状态包括排队、预检、下发中、远端执行中、验证中、成功、失败、已符合、跳过、取消和待核实。含失败或待核实子项的汇总不能显示全成功。
- 数据库保存队列、领取状态和面板锁。后台重启后恢复排队目标；下发中的任务先读回核实，不盲目重发。
- 请求可能已送达但响应丢失时标记待核实，保留目标锁，直到读回确认最终状态或管理员处理。升级、安装、卸载和证书签发不自动重复提交。
- 同步接口也需读回校验。“加入队列”和“已启动”只表示开始监控。宝塔存在不同任务队列，不能仅调用 `/task` 或看到队列为空就宣布安装成功。
- 每次适配器下发最多发起一个变更 API 请求，但一个请求可能包含上述 SSL 自动同步等服务端副作用，必须按完整范围冻结意图及确认。伪静态 child status=true 不证明重载；只读文件核验不能解除其待核实状态。
- 取消只作用于尚未下发的对象，不承诺停止远端已经开始的变更。重试保留原任务关联，并重新检查资源与状态。

## 权限与敏感信息

新增任务查看、创建、执行、取消和管理权限；API 凭据编辑沿用面板管理权限并独立检查。普通用户默认只看自己的任务，管理员可看全部。现有面板分组用于组织和选择，不宣称已经提供客户租户隔离。

结果按操作提取允许展示的字段，不打印原始响应。API 密钥、签名、登录密码、数据库密码、Cookie、证书私钥及 PEM 内容不得进入任务日志、浏览器返回、异常栈或 GitHub。

## 接口证据与兼容策略

已读取官方现行 API 索引中的全部 107 个说明页，整理为 19 类、373 条现行文档操作记录；另附一条旧版面板更新记录。此前草案遗漏了 ACME、SSL 两个带括号注释的 SetCertToSite 操作，现已补齐。

另外静态查看宝塔官方下载的 11.7.0、13.1.0 更新包，没有执行其中程序或脚本。软件操作已找到官方实现依据，但源码核对不能代替真实面板联调。

| 能力 | 接口依据与版本差异 |
|---|---|
| 面板升级 | 现代 `/system?action=upgrade_panel`；无 force 参数时查询，有 force 参数时执行指定 version。不能将 force=false 当查询，因为源码按参数存在与否分支 |
| 旧升级入口 | `/ajax?action=UpdatePanel` 存在服务端 force / autoUpdate.pl 自动进入更新的分支，禁止用于预检 |
| 建站 | `/site?action=AddSite`；读回面板内的网站和域名映射 |
| 防跨站 | `/site?action=multiple_basedir`、`GetDirUserINI`；对应 PHP open_basedir |
| 伪静态 | `GetRewriteList(s)`、`SetRewriteTel`、`SetRewriteLists`；显式拒绝时核对回滚，保存成功但重载未知时保持待核实 |
| SSL | `/acme` 的 `apply_cert_api`、`renew_cert` 会自动同步面板内符合条件的同 SAN 证书；条件需要时另发 `SetCertToSite`，配合 `GetSSL` 读回 |
| 软件安装/卸载 | `/plugin?action=install_plugin`、`uninstall_plugin`；安装使用面板返回的 sName、version、min_version、type，不能从用户文本拼接 |
| PHP 扩展 | `/ajax?action=GetPHPConfig` 查询该分支的扩展；`/files?action=InstallSoft` 按已校验的 name、version、type 下发 |

适配器按实测面板版本和响应结构启用。未知版本先进行无软件变更的连接与能力检查；未验证的变更接口显示“不支持当前版本”，不通过试发变更请求探测能力。

文档与程序冲突时以实际版本实现及联调为准。例如，官方文档中的 DNS 自动验证描述与 13.1.0 的 apply_dns_auth 手动验证实现存在差异，因此第一版采用 HTTP 文件验证。

接口调研明细及下载包哈希见 `docs/research/2026-10-22-baota-api.md`。

## 验证与交付

先用受控模拟 API 验证八类操作的参数、签名、结果判断与异常恢复，再用隔离测试面板验证真实接口。SSL 使用可控验证环境测试签发与部署，不对客户域名批量申请作为开发测试。

重点覆盖网站 ID 跨面板冲突、域名冲突、PHP/扩展不适用、配置校验失败、SSL pending/签发后部署失败、远端任务干扰、提交超时、后台重启、权限及日志脱敏。记录中区分模拟测试、静态源码核对和真实版本验证。

通过前后端测试、生产构建及独立代码审查后，部署前备份现有数据库、完整数据卷、持久加密密钥和部署配置。保留用户已经添加的面板记录。

GitHub 使用用户 Fork 的独立分支及 PR 保存设计、实现、测试和部署记录；固定提交构建镜像，记录部署标签与回滚流程。部署新功能不自动给客户面板执行任务，实际操作由用户在界面选择并提交。
