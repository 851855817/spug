# 宝塔面板一键登录

用户要求列表中的“打开”直接进入对应宝塔。已有网址、账户、密码继续加密保存；浏览器跨域登录采用宝塔 Linux 面板官方 API 的一次性票据，而不是在网址中传递密码或模拟绕过验证码。

## 合同

- 列表“打开”使用保存的 API 配置 POST `/config?action=get_tmp_token`，只接受 `status is True` 和 64 位 ASCII 字母、数字、下划线票据，跳转到保存的 API 基础地址下 `/login?tmp_token=…`。官方 9.2、11.7、13.1 源码均支持此协议。票据约 120 秒有效、成功使用后失效，新票据会替换旧票据。
- 官方 API 票据登录的是宝塔主管理员，而不是记录中任意子账户。新增独立权限 `baota.panel.login`，同时要求 `baota.panel.view`；不自动授予旧角色。超级管理员直接可用。
- 只有账户密码、没有 API 的记录明确提示先在编辑中配置 API；保留单独的“登录页”链接。不能声称保存密码就能绕过面板的验证码、二次验证或跨域 Cookie 限制。
- 后端只收记录 ID，使用现有有界、禁重定向、校验证书的签名客户端，不接受调用方提供地址或密钥。网络调用不持有数据库事务。调用前后从数据库核对账户状态、令牌和实际角色权限；返回前重新核对面板地址及 API 配置，撤销或变更后不返回票据。
- 响应禁止缓存；不落库、不记录票据，不回传远端任意错误正文。接口仅 POST。浏览器同步打开空白页，禁用 opener/referrer；成功后校验地址属于该记录的 API 登录地址才导航，失败关闭空白页，禁止重复点击。

## 发布

新增固定 `panel-login` 增量发布配置，仅覆盖 `apps/baota/login_views.py` 和 `apps/baota/urls.py`，UI 仅允许宝塔列表和角色权限定义。无迁移、无权限数据更新。保全现有 PHP 与健康模块；新模块在基准中必须不存在，回退按收据删除，两份 API 根和完整业务摘要必须恢复一致。复用现有配对备份、空闲门和受控发布器，隔离测试使用本地模拟接口，不调用客户真实登录或任务。
