# 首页运维概览与个人导航排序

用户要求服务器监控放在首页，待办展示证书到期；已选择同时展示服务器到期。另要求左侧子栏目拖拽，已选择同一分组内排序。沿用现有隔离工作树、feature/operations-reliability 和草稿 PR #4。

## 选择

采用复用监控卡片和既有本地查询接口的轻量首页：避免复制监控中心或新增采集服务。单纯链接无法满足首页查看指标；首页默认自动连接所有客户会增加额外采集，因此首页默认每 60 秒刷新缓存，用户可主动采集或开启原有自动采集。

## 首页

- 工作台顶部完整展示服务器监控，复用现有分组、搜索、分页、卡片、单台／全部主动采集与可选自动采集。仅展示用户有权限且已经开启监控的资源，确认关联仍按既有规则合并。不重复显示面包屑。
- 嵌入模式默认关闭自动采集，每 60 秒只 GET Spug 已保存的监控数据；隐藏或离开页面暂停刷新，单台采集中不被后台列表刷新打断。原监控中心的默认行为保持。首页刷新按钮明确为刷新缓存。
- 下方待办及系统公告并排，小屏纵排，便捷导航保留。待办使用当前管理员可访问的证书库存与到期资产 GET 接口，分别显示证书已过期／30 天内、服务器已过期／30 天内的总数和前 3 条；无需开启提醒。零结果、失败及证书数据不完整明确区分，不把未采集当作正常。
- 待办类别跳转同状态全列表，具体条目携带服务器／关键词。目标页只读取白名单查询参数并同步可见筛选，忽略非法参数，禁止把 URL 变成任务下发。待办每 60 秒更新，隐藏页停止，旧响应不覆盖新请求，失败独立显示。

## 导航

- 展开侧栏可点击“调整导航”，同一组的可见子栏目出现拖动手柄。拖到目标位置即时保存，上移放在目标前、下移放在目标后，支持移到组首／末尾；Alt+上／下提供键盘排序。调整模式不触发页面跳转，普通模式链接行为保持。
- 排序按当前账户保存在当前浏览器；不是所有用户共享配置，不涉及跨设备同步。保存失败提示但保留本次顺序。完成、恢复默认均可用。
- 用原路由路径作为身份，保存内容只有顺序。渲染时先过滤权限和无标题路由，再合并排序；重复、未知、畸形条目忽略，新栏目追加。跨分组拖放无效，不改路由、权限或用户凭据。

## 验证及发布

真实组件测试覆盖首页无自动 POST、缓存刷新／暂停／主动采集、待办四类／权限／失败／跳转、目标筛选、导航同组拖动／键盘／保存／账户隔离／恢复／跨组拒绝。先失败后实现，执行全前端回归与发布保护；无 API／模型／迁移变化。正式构建以模拟接口验收，再经精确 UI 白名单发布配置、新配对备份、完整 API 保全及业务空闲检查发布；不主动采集真实客户，不改变监控和提醒开关。
