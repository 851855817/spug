# 宝塔面板管理：第一版设计

日期：2026-10-22

## 目标与入口

基于当前运行的 Spug 4.1.1，在左侧导航“主机管理”下方新增同级菜单“宝塔面板管理”。沿用现有 Ant Design 风格，采用左侧分组树、右侧面板列表的布局。

已核实当前镜像对应上游提交 `049984e01373fc1cd97b94b60c0b3124036b0f47`。

## 方案比较

1. 推荐：在 Spug 内新增独立模块。列表、表单、登录和权限体系融为一体，便于后续扩展宝塔接口管理。
2. 外挂独立应用：开发边界清晰，但需要维护额外服务、登录对接和导航集成。
3. 扩展现有凭据管理：改动较少，但难以提供用户要求的分组面板列表，也会混合 SSH 凭据和面板记录。

## 页面与操作

- 分组树支持新增、重命名、删除，以及按分组筛选；有面板记录或子分组时阻止删除分组，提示先移动记录或处理子分组。
- 列表显示面板名称、地址、账户、分组、备注、创建时间和操作。
- 支持搜索名称、地址和账户，刷新列表与分页。
- “添加面板”打开表单；保存后刷新列表。
- 支持编辑和带确认提示的删除。
- “打开面板”在新标签页打开保存的完整地址。

## 表单

| 字段 | 规则 |
| --- | --- |
| 面板名称 | 必填，便于识别 |
| 所属分组 | 必填，可选择或先创建分组 |
| 面板地址 | 必填，合法 HTTP/HTTPS 地址，支持自定义端口和宝塔安全入口路径 |
| 登录账户 | 必填 |
| 登录密码 | 新增必填；编辑时留空保留原密码，填写新值则替换 |
| 备注 | 选填 |

示例地址：`https://example.com:8888/security-entry`。完整路径会保存下来。密码输入内容不执行 trim 等修改。

## 密码与权限

密码由后端加密后写入数据库，加密密钥保存在服务器持久化目录并限制文件权限；数据库和密钥需要配套备份。列表和编辑接口仅返回“已设置密码”的状态，不返回密码原文。

页面及接口复用 Spug 登录认证，并新增宝塔模块的查看、新增/编辑、删除、分组管理权限。超级管理员可使用全部功能，其他账户按角色授权。

## 功能边界

本版的“打开面板”表示打开宝塔登录页面。仅保存账户密码不能保证绕过宝塔的验证码、双重认证等登录流程；自动登录如有需要，单独设计。本版保存记录时不要求宝塔在线，也不以登录校验作为保存条件。

## 实现与部署

新增 Django 数据模型、数据库迁移、接口与 React 页面，导航和角色权限沿用项目既有结构。

官方镜像入口脚本会在每次启动时把 `/opt/spug` 的程序同步到 `/data/spug`。因此采用基于当前固定镜像构建的二开镜像，把修改编入镜像内源目录，确保重启后仍然保留。

实施时先备份数据库、Spug 数据和部署配置，构建并验证后切换到二开镜像。记录源码版本和回滚方式，保持现有访问入口。

## 验收

1. 侧边栏出现新菜单，页面风格与主机管理一致。
2. 可创建分组，添加包含安全入口路径的面板地址、账户和密码，刷新后记录仍在。
3. 搜索、分组筛选、编辑、删除和打开面板正常。
4. 编辑时密码留空不覆盖原密码，列表与编辑响应不泄露密码。
5. 未登录和无对应权限账户不能访问受限接口。
6. 重启二开容器后菜单、功能和数据仍然存在，原有主机管理保持可用。
