# SSL 配置状态分类修复

用户已授权直接修复。未开启 SSL 的网站不能混入“检查失败”。

- 宝塔 GetSSL 返回布尔 false，且固定网站主配置经重复摘要核对未启用 SSL，才标记“未配置 SSL”。说明限于宝塔开关与主配置；不宣称已遍历 include 或整机无证书。
- 配置读取失败、公开证书读取失败、API 与主配置不一致分别保存固定公开诊断码；不得凭空证书推断未配置。历史缺少证据时显示待核实，下一次正式巡检更新。
- 诊断码随现有冻结 plan 保存并校验枚举，无模型或迁移变化，不保存配置正文、私钥或错误原文。续签仍走原有权限、部署与预检约束。
- 增加可点击“未配置 SSL”统计，与“检查失败”互斥。检查失败保留未知及实际异常；详情保留公网 SNI 的独立结果，并显示准确原因与处理方向。
- 保持旧缓存排除、个人隐藏和提醒、权限与来源开关行为。发布不修改来源配置，不执行续签。
- 隔离测试验证 disabled、读取失败、状态不一致、标准 include 未遍历、历史无诊断、域名不匹配、统计筛选以及前端显示。以新固定范围发布合同上线，重新完成空闲门、保全、备份和回退验证。
