# 账号资源权限与服务器数量配额

状态：供用户审查的完整方案，未实施、未上线。用户已确认统一限制服务器总数，明确关联的同一台 SSH 与宝塔合并计 1 台。沿用 feature/operations-reliability 与草稿 PR #4，不合并主分支。

## 目标与边界

管理员创建 A 账号时，可设置其角色、可管理服务器数量和具体操作权限。普通账号自行添加的 SSH 主机、宝塔面板归自己管理；其他账号默认不可查看或操作。管理员可明确分配已有资源。服务器相关列表、详情、统计、下拉选择、任务、监控、证书、提醒和日志使用相同的数据范围。

这次围绕现有内部员工账号，采用“功能权限 × 资源范围 × 配额”的共同判断，不引入计费、套餐、组织租户或注册前台。

## 方案选择

1. **推荐：账号归属＋显式资源授权＋统一配额。** 复用现有岗位角色，将数据范围与角色操作权限分开；所有接口、队列和 WebSocket 共用后端校验。能覆盖自主添加和跨页面隔离。
2. **仅扩充主机组授权。** 改动较少，但宝塔、证书等未统一使用主机组，不能直接解决个人归属、数量配额和异步执行授权，故不采用。
3. **组织／租户体系。** 适合未来对外经营或团队层级管理，当前会增加无关复杂度，暂不实施。

## 管理员创建／编辑账号

- 岗位角色：沿用五类岗位模板；多个角色仍合并功能权限，但不能绕过账号数据范围和配额。
- 数据范围：默认“本人资源”；可增加“管理员指定的资源”。普通账号没有自行设置全站范围、资源归属、授权或配额的权限。
- 服务器总数上限：整数 0 及以上；0 表示不允许添加或获分配服务器，“不限”是单独显式选项，仅管理员可设置。新普通账号默认 0，管理员授予具体数量后使用。
- 已用／上限：例如 `3 / 5 台`，区分本人添加与管理员分配，但两者都计入总额度。账号内同一台的多个可见连接去重计算。
- 功能权限：通过角色逐项勾选；管理员能预览该账号最终生效的功能、资源和剩余额度。
- 平台超级管理员继续拥有全局管理，不受普通账号配额影响。

## 普通账号的权限分布

所有“允许”还须同时满足该账号的岗位操作授权，以及该资源是否在本人／指定范围。

| 功能 | 可分别授权的操作 | 数据范围与边界 |
| --- | --- | --- |
| 主机管理 | 查看、添加、编辑、移除记录、导入、导出、验证连接 | 本人或指定主机；添加和导入必须检查配额；删除平台记录与删除远程文件是不同权限 |
| 宝塔面板 | 查看、添加、编辑、移除记录、测试连接、一键登录 | 本人或指定面板；一键登录单独授权，不随查看权限开放；不返回保存的口令、API 密钥和私钥原文 |
| 资源分组 | 查看、创建、编辑、移动、删除自己的分组 | 只展示本人分组和必要的授权范围；同组不自动共享其他账号资源，不允许将他人资源移入自己的分组 |
| 服务器监控 | 查看、开启／关闭、主动采集 | 只展示有权服务器；首页卡片、详情弹窗和全局采集范围一致 |
| SSL 监控 | 查看、配置来源、巡检、申请／续签 | 仅有权来源及其网站、证书、提醒；查看不等于可续签；显示隐藏和不再提醒继续仅对当前账号生效 |
| 运维作业／面板任务 | 查看、创建巡检、确认执行、取消、人工判定 | 只选择有权目标；任务和结果限制为本人创建且所有目标仍在授权范围内；超级管理员可全局审计 |
| 面板操作项目 | 添加网站、防跨站、伪静态、申请／续签 SSL、上传、升级面板、安装／更新／卸载软件、安装 PHP 扩展 | 分项授权，保留任务创建和执行权限；得到“执行面板任务”不再自动得到所有升级、安装和卸载操作 |
| SSH／文件 | 终端、文件列表、上传／覆盖、删除远程文件、批量命令 | 每项独立授权；只允许有权主机；执行模板不授予模板内其他目标或命令权限 |
| 任务计划 | 查看、创建／编辑、启用／停用、运行、删除计划 | 本人计划及有权目标；到时执行重新检查账号、权限和目标范围，不因创建时曾有权限而永久允许执行 |
| 网站、备份、软件与 PHP 数据 | 查看、主动采集、发起相关任务 | 来源服务器必须有权；具体远程动作继续检查对应任务权限 |
| 服务器到期、待办、通知 | 查看、跟进、编辑到期信息、设置自己的提醒 | 仅有权服务器及其到期事项；统计、通知正文和跳转链接同样限制范围 |
| 模板与执行历史 | 查看、创建、编辑、删除／使用 | 本人模板；管理员发布的公共模板可只读使用，使用时仍重新验证实际目标和执行权限；不展示其他账号历史 |
| 应用发布／流水线／既有监控任务 | 沿用原有功能及应用、环境授权 | 还须检查其中全部服务器在当前账号资源范围；无关模块不引入新的自动授权 |
| 系统管理 | 账号、角色、配额、归属、共享、平台健康和全站设置 | 继续由平台管理员管理；个人设置只修改本人配置 |

分配资源采用“只读”或“管理”两种显式上限。只读授权不能因岗位角色含执行权限而变成可操作；管理授权也不能超过角色勾选的功能。没有资源授权时，即使知道服务器 ID、任务 ID、文件下载地址或 WebSocket 地址也不能访问。

## 统一配额规则

- 计数涵盖未验证主机、未配置 API 的宝塔、关闭监控的资源和管理员指定的资源，避免利用状态绕过额度。监控开关和页面隐藏不释放额度。
- 管理员明确确认的 SSH↔宝塔关联才允许去重；不按相同 IP 自动合并。关联只用于去重和显示，不能把另一侧连接、凭据、网站或权限传播给当前账号。
- 普通账号不能随意关联、改归属或共享资源来绕过配额。同台关联由管理员确认和维护；已存在确认关联继续使用，本次不另建关联申请流程。
- 添加单台、批量导入、管理员分配、归属转移和关联解除都使用统一的并发配额检查；不能通过同时提交多个请求超额。
- 批量导入先检查本次所需净额度，不足则整批拒绝并说明剩余额度，不静默导入一部分。仅提交成功的资源记录消耗额度，不使用暂存配额或申请占位。创建前连接验证失败且未生成记录时不消耗额度；已创建但未验证或连接失败的记录仍计数。
- 若创建前包含网络验证，先完成验证，再在同一数据库事务内锁定受影响账号的配额状态、重新计算净用量并创建记录；不跨网络请求持有配额锁。多账号分配或转移按固定账号顺序加锁，避免反向锁定。
- 超额时提示：`当前已管理 5 / 5 台服务器，无法再添加；请联系管理员调整额度。`
- 管理员把上限调低至已用数以下时，保留原记录和已有访问，不自动删除、不打断已经发出的操作；阻止新增、分配和其他增加净占用的动作。角色或资源授权撤销仍独立生效。
- 管理员可收回分配；移除已无引用的记录后释放相应净额度。删除有历史引用资源仍遵循现有保留规则，不为释放配额删除审计或任务历史。

## 后端执行规则

1. 后端统一计算“活跃账号＋功能授权＋资源授权”，先限制数据查询，再统计、搜索、筛选和分页；前端菜单与按钮仅呈现生效权限。
2. 单条编辑、删除、重试、登录票据、导入导出和批量操作都核对实际资源。普通账号的多目标请求夹带任何无权目标，整次请求拒绝，不悄悄执行部分服务器。
3. 任务的预检、确认、队列取出、每个目标下发与重试阶段重新核对账号状态和资源权限。权限撤销后停止未下发动作；对已发出的远程动作只跟踪结果，不承诺撤销已经执行的命令。
4. 已打开的终端、文件与结果流在账号禁用或授权撤销后断开／停止继续发送；不能继续复用旧票据。账户、角色和资源授权变更使权限缓存失效。
5. 旧混合范围任务不向普通账号输出可能含其他服务器的总体摘要、目标快照、日志或计数。管理员保留全量审计；普通账号只访问本人且全部目标仍有权的任务。
6. 凭据不作为前端数据导出。新普通账号添加服务器时使用获授权的连接凭据，不能自动借用平台全局 SSH 私钥取得未授权服务器的访问能力。
7. 资源分配、配额调整、归属转移、关联与拒绝操作记录操作者、对象和时间；审计不得记录口令、密钥或原始配置。

## 旧数据与上线

既有创建者作为默认资源归属的依据，额外分配由管理员明确设置；不会将原先宝塔全局列表的可见性自动转成所有普通账号永久授权。资源创建者和运维负责人是不同概念，不把到期跟进负责人直接当所有者。归属转移保留原创建审计。

上线前只读生成账号、资源、确认关联、既有组授权、在途任务与计划的影响清单。管理员账号维持全局范围；既有普通账号的初始额度按其保留资源的净用量建立，新增额度由管理员设置。每项旧组授权与新资源范围冲突必须列明，不静默扩大授权或丢失记录。

实现分三段，但作为一个完整权限功能验收：先账号策略／归属／配额和主机宝塔入口，再所有跨页面查询与统计，最后异步任务、计划、终端及细分动作权限。全部通过后才宣称普通账号隔离完成；不在跨模块规则尚不完整时开放普通账号执行能力。

本次涉及权限和附加数据结构，不能套用上一轮只替换三个 SSL 模块的发布合同。实施计划需根据最终模型建立精确发布范围、附加迁移、既有账号回填、兼容回退及业务保全；重新核实现网、业务空闲和新配对备份后才能上线。开发与测试只用隔离数据库和模拟客户接口，不为测试创建真实客户命令、续签或监控采集。

## 验收示例与测试

管理员给 A 勾选添加／管理自己服务器、监控查看与巡检权限，上限 5 台。A 添加 2 台 SSH 和 2 个宝塔；其中 1 对经确认同台关联，显示已用 3／5。A 再添加 2 台后为 5／5，第 6 台被后端拒绝。

A 在首页、服务器监控、SSL、任务目标、任务计划、到期管理、通知及导出里只看到这 5 台对应数据。B 默认看不到 A 的记录，直接换 ID 也不能读取或操作。A 未获续签或升级权限时不能执行这些动作，拥有查看权限也不能一键登录宝塔；管理员仍可查看全局。

必须覆盖：A／B／管理员及只读共享矩阵；列表、详情、统计、搜索、导出、下载、登录票据和 WebSocket 的跨账号越权；两个并发新增不能突破剩余 1 个名额；导入、分配、解绑、转移和调低额度；任务排队后撤权、禁用和角色修改；计划执行前撤权；原有五类岗位模板及管理员功能回归。配额锁和并发必须在 MariaDB 隔离验收，不能只靠 SQLite 通过推断正确。
