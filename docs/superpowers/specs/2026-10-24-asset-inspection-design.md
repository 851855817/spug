# 网站证书、备份与巡检体验设计

用户选择三个候选功能“全部”，延续此前直接开发及部署授权；本轮不重复要求确认。采用现有隔离工作区和开发分支，分模块验证后发布。

## 方案选择

采用本平台现有宝塔 API 和数据库缓存，手动采集、按面板顺序处理。外部证书引擎会引入新的凭据及运行服务，首轮不集成；后台定时全量扫描会增加负载，首轮不启用。SSL 展示为面板登记摘要，不宣称源站或 CDN 实际握手已核验。

## 网站与证书、备份检查台

新增“批量执行 → 网站与证书”“备份检查台”，首轮仅超级管理员，复用宝塔已有 API 配置，不另填密码或密钥。列表读取本地快照，只有用户主动点击采集才请求客户面板。选择面板或分组，前端顺序采集，服务器用持久租约限制全局采集并发为一；单面板总时限和资源数有上限、短冷却，重复采集和错误均脱敏。API 配置发生变化时旧快照标为失效，采集期间变化不能写为新鲜结果。失败保留上次成功数据并明确过期，不能将失败当作空资产。

网站展示服务器/IP/分组、网站/域名、PHP、站点状态、SSL 到期日，按分组、服务器、关键字、SSL 状态筛选和分页；无 SSL、过期、30 天内临期、未知分别展示。提供跳转现有证书任务的入口，只带选择上下文，不创建/执行变更。只保留字段白名单，不存储私钥或完整配置。

备份按网站、数据库资源列出最近一条登记备份及采集结果，保留无记录资源；显示备份时间、大小、面板报告的本地文件存在状态和进行中状态。支持 24/48/72/168 小时阈值筛选（默认48），明确本地副本与云端记录的差异。官方接口没有证实的字段为未知；不下载/解压备份，不触发备份、恢复、清理或云端凭据查询。面板声称本地存在且非空不代表归档完整或恢复成功。查询端点的面板自身缓存/标记副作用在指南披露。

## 巡检结果体验

保留执行与熔断语义。执行记录新增“查看结果”操作，显示检查异常/未知统计；详情自动定位到结果区域，顶部解释采集结果与健康状态差别，突出失败/待核实/指标异常/未知，提供“只看需处理”快捷筛选和失败处理建议。浏览器刷新可通过 URL 作业编号恢复详情，不重新执行。创建后切换执行记录并展示结果。避免自动启动、自动继续或自动修复。

## 验证和发布

权限、分页、状态分类、配置漂移、失败保留快照、全局并发/超时、缺失与云端状态分别做后端测试；前端验证采集仅由点击触发、顺序/隐藏页取消后续请求、旧响应隔离、异常筛选、结果深链与报告。备份协议对照固定官方版本源码。全量测试和生产构建后，在隔离运行时/MariaDB演练新增迁移；生产配对备份、保全摘要与兼容回退，新页面只读验收，不把客户真实采集当开发测试。
