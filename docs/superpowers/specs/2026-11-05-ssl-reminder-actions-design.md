# SSL 证书列表直接管理本次提醒

用户要求在 SSL 证书巡检页面增加“不再提醒”，沿用此前已确认的当前账号、当前证书周期生效规则。现有到期提醒区已有该操作，列表没有直接入口。

在证书列表增加“提醒”列：当前有效到期提醒显示“不再提醒”；已忽略的显示“恢复提醒”；来源未开启到期提醒显示“未开启提醒”，尚无有效到期提醒显示“暂无到期提醒”。保留证书和统计，忽略只减少该账号的本轮到期提醒；其他管理员、后续到期阶段和换证周期沿用既有服务逻辑。无效／旧缓存不构造新的提醒，不用点击忽略开启来源或提醒。

列表 API 附加当前账号的有效 reminder id 与 muted，复用已有本地提醒查询及原 mute POST。列表与上方提醒区双向刷新，保存失败维持原状态；防重复提交、卸载和换账号后不应用迟到响应。不增加 API 路由、权限、schema 或客户连接。

实现范围为 SSL service.py、SSL 列表 index.js 和 Reminders.js；测试覆盖账号隔离、跨阶段／换证、GET 无写入、无提醒情况、列表忽略和恢复、双向刷新、失败及换账号保护。固定发布 profile 仅允许上述三份运行文件，保全其余 API、PHP 和平台健康、既有 schema 和 SSL 数据；重新核实现网、空闲、配对备份与兼容回退。
