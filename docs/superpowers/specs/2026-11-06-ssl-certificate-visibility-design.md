# SSL 过期证书显示管理方案

用户希望截图中已经过期、目前不需要处理的网站证书可以选择不显示。现有“不再提醒”只屏蔽个人到期通知，不能控制证书列表显示。本方案处于用户审查阶段，尚未实现或部署。

## 推荐：逐条隐藏

过期证书行增加“隐藏”，点击后从当前账号的默认证书列表移除。列表上方增加“查看已隐藏”，切换后可以看到被隐藏的记录，并逐条“恢复显示”。同一域名在不同服务器上的记录可分别选择。只影响当前账号，刷新、重新登录和换浏览器后保持；其他账号照常查看。

隐藏仅针对当前证书周期，以证书指纹和到期时间共同确定。巡检发现证书已更换后自动恢复显示，避免新证书的后续异常长期被屏蔽。证书和历史任务均保留，采集及提醒继续使用原有设置。“隐藏”和“不再提醒”是两个独立操作。

列表总数、分页和上方统计使用当前可见范围计算，避免隐藏后留下空页或统计不一致。“查看已隐藏”切换后的统计同样按该范围计算。搜索、分组、服务器和证书状态筛选均可叠加；切换视图和隐藏操作后返回第一页。明确显示当前正在查看隐藏项，保留恢复入口。

## 备选：统一隐藏所有过期

仅增加一个“隐藏已过期”开关，按当前账号保存，启用后列表排除全部过期记录，关闭即可全部恢复。这个方案操作更少，但不能保留某条需要跟进的过期证书。二者先选择一种，避免新增重复控制项。

## 实现与验证边界

推荐方案复用既有 UserSetting 表的独立账号设置项，不增加模型或迁移。保存当前证书 ID 与周期摘要，由 SSL 服务在本地列表筛选、分页和统计之前应用。专用本地 POST 验证当前账号权限、证书存在及当前过期周期；恢复操作只能改变本人偏好。GET 不写入，不联系客户服务器。操作失败保留当前视图，显示简洁错误并允许重试；前端沿用重复点击、卸载和账号切换保护。

测试覆盖账号隔离、逐条隐藏／恢复、换证自动显示、跨页计数与筛选、提醒不受影响、GET 无写入和无远程调用、保存失败及换账号迟到响应。按实际已上线版本重新制作精确发布 profile，保全现有 API、用户数据和设置，完成生产构建、模拟浏览器验收、隔离回归、新配对备份及上线核验；验证只读取本地证书缓存，不主动巡检或续签客户证书。
