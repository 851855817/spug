# 个人“不再提醒”

用户要求在待办事项／事务提醒后添加“不再提醒”，已确认仅影响当前账号，其他账号继续提醒。对有到期日期的事项，屏蔽本次日期，日期更新后重新展示；提供恢复入口。

范围：首页证书／服务器到期待办、顶栏通知列表与实时提醒、到期管理站内提醒。每条右侧增加文字按钮，点击不触发该条导航或全局标记已读。点击成功后隐藏，失败保留原条目并显示简短错误。各入口提供“已忽略”管理与逐条恢复；不屏蔽整类事项或安全诊断警告。

复用 `/api/setting/user/` 的按用户隔离持久设置，不新增模型、迁移或后台运行 API。每个资源独立存为 `mute:v1:` 加随机 24 位十六进制后缀的设置行（长度 32），value 保存版本、完整身份、周期、标签和 muted。身份／周期严格比较；同一身份更新复用原行。独立行避免修改不同事项时相互覆盖。恢复前重新读取个人设置并恢复该身份／周期全部匹配记录，以处理跨浏览器重复设置。失败不宣称已保存，服务响应更新本地共享状态，账号／会话变化隔离旧异步响应。用 crypto.getRandomValues 生成设置键，兼容现有 HTTPS 与本机 HTTP。

证书身份为 panel_id＋site_id／库存 id，服务器身份为规范 asset key；二者周期为完整到期日期。到期管理提醒复用服务器身份＋到期日期，因此首页屏蔽与站内提醒一致。缺少有效身份／日期时不允许误屏蔽。通知以不可变消息 id 标识，周期使用消息创建时间；新的消息 id 仍可提醒。实时 WebSocket 只有标题／内容，收到后重新读取本地通知列表，匹配消息 id 再应用个人屏蔽；不能可靠匹配时正常展示，不能用标题屏蔽以后所有新故障。

首页每类读取本地库存前 20 条并展示最多三条未忽略事项，屏蔽后优先补充当前页下一条；当前页全部忽略时明确提示可点击标题查看全部，不伪装全类为空。个人隐藏不删除原始数据，目标资产库存及历史记录保持。到期提醒表保留真实服务端总数与未读计数，隐藏过滤按页提示并可恢复，不篡改全局统计。

测试只使用隔离数据库与模拟接口，验证当前账号隔离、日期变化、新消息仍提醒、恢复、刷新持久、失败不误隐藏、按钮不导航以及无全局已读写入。发布使用新增固定 UI-only 配置，精确运行文件白名单、完整 API 树保全、新配对备份、四入口兼容回退。构建继续绑定实际公开源码提交，保留所有版权与 AGPL 说明。
