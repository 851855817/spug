# 库存提醒入口与岗位权限模板

用户要求在网站与证书清单补充“不再提醒”，沿用已确认的当前账号、当前到期周期规则。在证书任务列续签链接后显示提醒操作；忽略后保留资产行及原统计，可直接恢复，也可在“已忽略”管理。仅临期／已过期且有可靠身份日期的证书提供按钮。复用既有个人偏好组件，首页同步；备份页面不受影响。

用户随后要求根据内部员工职位预设角色模板，已确认五类：只读审计、值班运维、网站运维、发布工程师、运维主管。在角色的功能权限页面提供岗位选择、权限与风险预览、套用到草稿；管理员核对勾选后保存。取消不写角色，不直接修改现有员工授权。模板必须使用现有实际可配置权限码，明确 SSH 主机与应用资源仍需单独分配，现有仅超级管理员可访问的模块不能通过模板越权。

只读审计仅含查看；值班运维可通过授权 SSH 终端和批量命令排障，默认不含面板执行与免登录；网站运维只创建面板预检，因为执行权限同时包含升级、安装及卸载；发布工程师可构建与发布、执行既有流水线但无发布审核；运维主管包含面板执行、人工判定、免登录和发布审核，仍不是平台超级管理员。不默认加入删除权限，不自动选中全部现有或将来权限。宝塔与面板任务目前无客户组隔离，界面明确提示。

验证使用模拟接口和隔离数据库；不执行客户任务或主动采集。只修改 UI，不变更权限校验 API、模型或线上角色数据。发布使用精确固定 UI 白名单、完整 API 树保全、新配对备份与四入口回退，保留 AGPL 和实际公开提交源码入口。
