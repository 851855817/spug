# SSH SSL 巡检兼容与失败状态修正

延续已授权的 SSH／宝塔 SSL 自动发现功能，修复本聊天复现的三处缺陷：普通 Nginx location 正则中的结束锚点 `$` 被错误当成动态证书配置；从未成功采集的来源因空摘要而被错误显示为“配置已变化”；远端已知解析错误在返回时被合并成 unsupported，无法解释失败原因。

仅允许 location 的静态匹配表达式包含 `$`。证书路径、配置引用、端口和动态证书选择继续使用原限制，读取范围、限额和续签执行权限不扩大。SSH 来源仍需已验证连接、Python 3，以及可读取的受支持 Nginx／Apache 配置和公开证书；不要求宝塔 API 或 ACME 客户端。ACME 仅用于既有订单续签。

来源只有存在成功快照摘要时才比较该摘要。没有成功快照时显示持久化的待检查或失败状态，不伪造配置变更；成功后真实连接变更仍使旧缓存失效，任务准入与运行时的配置、权限及租约检查保持原样。

固定错误码区分配置语法、动态证书或路径、引用缺失／越界／循环、权限或文件不可读、编码、非常规文件和读取限额，提供固定中文原因与处理方向。未知异常继续隐藏原始异常，公开 API 不返回客户配置内容、凭据或远程 stderr。复用现有任务结果和来源状态展示，无新表、迁移、路由或 UI 行为。

以隔离数据库和临时文件树覆盖兼容、边界和错误传递。发布采用精确三个 API 文件 overlay，保全完整运行树和用户数据，重新执行空闲、配对备份与兼容回退检查。验证和发布不连接客户服务器、不主动巡检、不调整用户开关；真实巡检由用户从既有入口发起。
