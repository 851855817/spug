## 方案与边界

当前 Docker 仅映射 `127.0.0.1:8080:80`，原应用 `4b051b1` 正常；宿主机没有 Nginx，80／443 未监听。采用宿主机 Nginx 反向代理到现有回环端口，支持 API、WebSocket、文件上传与长请求。相比重建容器改端口，此方式保持原应用、容器、数据卷、进程和 SSH 转发入口不变，失败时可独立停用公网代理。

优先签发可信 IP HTTPS 证书；确认 ACME 客户端支持 IP 与短有效期配置后，安排自动续签。HTTP 初始仅提供挑战文件及连通检查，成功配置 HTTPS 后跳转到固定 IP。若云安全组阻挡，先完成可核验的服务器配置，再请求用户仅放行所需端口，不改其他云规则或开放数据库／原生 API 端口。

不读取／输出凭据，不登录或操作客户服务器，不运行客户任务、采集、提醒或监控。保持应用权限和账户配置不变，代理覆盖外来转发 IP 头，日志不保存查询参数，避免 WebSocket 令牌写入新增访问日志。
