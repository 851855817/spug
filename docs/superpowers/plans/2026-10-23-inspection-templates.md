# 巡检模板整理与导入计划

目标：将用户选择的通用巡检、网站与 PHP 检查整理为可批量调用的 Spug 模板，保留公开来源与审查记录。

方案：12 个独立 Python 3.8+ 标准库模板，由公共辅助代码生成完整正文。固定命令、文件白名单、超时和输出上限；网站检查仅允许公网 HTTPS，验证证书，不跟随重定向。导入不关联主机、不创建执行记录。

- [x] 固定公开项目版本并只读审查选定文件，排除安装、邮件及无界扫描功能。
- [x] 在 `deploy/inspection-templates/tests/test_templates.py` 编写输入、文件、TLS、输出和导入碰撞测试，先确认失败。
- [x] 在 `deploy/inspection-templates/` 实现辅助库、12 个检查入口、清单与构建器；生成无需额外依赖的模板正文。
- [x] 运行隔离测试与静态检查，并由代码审查者复核；修复关键问题。
- [x] 先备份服务器模板，再事务性创建模板；同名内容不一致时拒绝覆盖。复核正文哈希、主机为空、执行历史不变。
- [x] 在后台查看模板列表，提交并推送 Git 分支，保存实际导入记录和兼容性限制。

验收：12 个模板包含来源、用途与局限；恶意域名、私网 DNS、软链接、非普通文件、超大文件、超时/输出溢出受控；仅导入，不在客户主机运行。
