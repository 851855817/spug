# Python 3.6 SSH SSL 真实环境兼容修复

任务 #57 的两个 SSH 来源均失败。经用户现有连接只读诊断，两台为 Python 3.6.8：旧版 shlex 在 `whitespace_split=True` 下不拆分 `epoll;`、`51200;`、`on;`，探针在 Nginx events 块关闭时错误报告 configuration_syntax。主配置尚未展开 include，失败与客户 SSL 配置本身无关。

方案：使用无外部依赖、兼容 Python 3.6 的有限 Nginx 分词器，区分结构分隔符与引号／转义内文字，不依赖 shlex 不同版本的标点行为。保留转义字符以继续拒绝动态或转义证书路径，不执行配置。仅修改既有 remote_probe.py；目录、限额、续签、权限、表和用户开关不变。
