# SSL 续签预检诊断修复计划

**目标：** DNS 证书被 HTTP 同订单续签预检阻止时，显示准确原因和下一步；不改变续签范围或重新执行已有任务。

**根因证据：** 已保存任务 #4 的子项目及冻结快照均为 failed，原证书 auth_type=dns，result 与 snapshot 均保存通用配置核对失败消息，无执行意图或远程结果。证书适配器拒绝非 HTTP 订单时抛出 PanelAPIError，site_preflight 为防止第三方异常泄密而统一掩盖消息。

**实现边界：** certificates.py 根据已解析的公开证书状态返回固定失败文案；保留未知异常的通用掩码。TaskItem.js 只对明确预检失败、无执行意图和远程结果的旧 DNS 快照补充诊断，不修改历史记录，不覆盖执行后错误。建议回原宝塔 DNS 订单续签；切换 HTTP 须确认解析和 80 端口后单独申请与预检，绝不自动切换。
