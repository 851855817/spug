# 侧栏分组折叠修复

用户报告在系统设置页点击“系统管理”折叠箭头无效。根因是 Sider 每次 render 检查当前路径，如果当前组不在 openKeys 里就立即 setOpenKeys 再次展开，覆盖用户的 onOpenChange。

**修复：** 使用 Router 的 pathname，自动展开只响应真实路径变化或整个侧栏展开。手动收起保留到下一次页面切换；选中项使用组件自己的状态，避免模块全局变量污染。权限过滤、同组拖拽排序、编辑模式及菜单结构保持。

**范围：** 一个运行 UI 文件 `spug_web/src/layout/Sider.js`，更新既有 `Sider.test.js`。添加精确单文件的 `sidebar-collapse-ui` 发布配置，沿用完整 API 不变、不可变镜像、空闲、配对备份及仅 UI 回退保护。继续现有分支与草稿 PR，不合并主分支。
