# 任务与作业结果精简

用户要求所有任务和作业只保留有效信息：结果状态、异常原因、具体数据。主结果优先显示，重复说明、基线比较和流水记录从页面移除。

## 范围

- 运维作业全部三类 Linux／PHP／Web 检查共用结果页：主机、结果状态、异常原因、检查数据。成功且检查项全部正常才标正常；指标异常或采集失败标异常并说明原因；未知、缺项与中断标待核实。未执行、执行中、取消独立显示。保留人工分批继续／取消、刷新、下载和读取失败提示。
- 面板任务各操作共用详情：保留目标、状态、异常、版本和目录等业务数据；去掉审计流水及重复正常说明，核验数据按需展开。预检执行前的影响确认和暂停异常保持；已结束不再堆叠批次提示。
- 文件上传结果只显示非零汇总及逐文件结果。原生命令、文件分发保留原始输出，明确当前执行状态和退出码；不根据任意输出文本推断服务器健康。
- 任务计划详情保留运行时间、汇总、逐台状态／退出码／耗时和实际输出，移除重复解释和多层统计卡。流水线结果保留节点状态、原始输出和连接异常，隐藏正常连接的技术提示。
- 记录列表本身已为简短状态／时间／结果入口，保持。存储、权限、任务执行、轮询合同和客户操作均不改变，后台历史不删除。
