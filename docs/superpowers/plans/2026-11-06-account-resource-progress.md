## 实现中，尚未上线

- 主机、分组、导入导出、SSH、文件与 WebSocket 已完成两阶段审查。最新组合 152 项通过，前端文件票据行为测试 1 项通过。真实 SSH 方法搭配模拟网络覆盖脚本上传后撤权、32 KiB 字节块传输、空闲复验、终端与挂载清理。普通账号只能在原确认的端点兼容使用管理员创建的旧全局密钥连接，修改端点必须独立凭据；管理员降级后也重新检查。
- 监控、SSL、网站库存、运维作业与到期已完成已实现范围两阶段审查；规格审查领域回归 335 项通过、10 项跳过，最终质量复核子集 103 项通过。修复缺独立 key 时来源状态崩溃、分组标签泄露、子进程输入和回复背压超时、DNS 后连接撤权与续签参数发送边界；本地轮询不产生逐次授权洪泛，空闲仍每秒复验。首页和通用通知纳入遗留入口段继续验收。

- 开放命令 API 携带模板身份，入口/结果核验创建者及全部目标；流水线目标解析涵盖构建主机与传输来源。新增模拟测试持续补充，尚待独立审查和其余流水线入口接入。
