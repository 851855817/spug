# 表格列宽拖动实现计划

目标：全站有表头的业务表格支持拖动右边界调宽，主机和宝塔列表优先实测。列宽在当前浏览器按页面、表格和列标识保存；双击分隔线恢复该表默认列宽。监控图标按用户参考改用折线图。

采用显式公共 `ResizableTable` 包装 Ant Design Table：比逐页重复事件处理更容易维护，比在 DOM 上全局注入手柄更能保留 React 状态、固定列和排序行为。接入公共 TableCard 及直接使用 Table 的页面；仅声明 Column 的页面继续使用原 Column。无需新增依赖或后端修改。

- [ ] 先写公共组件的拖动、边界、持久化、重置、列变化、已有表头行为和卸载清理测试，运行确认缺失功能导致失败。
- [ ] 实现公共组件、拖动手柄样式和安全的本地偏好读写。拖动开始时冻结当前表头实际列宽，限制 64–1600 px，禁止拖动触发排序；支持方向键调整。
- [ ] 接入 TableCard（使用既有 tKey）与全部直接渲染业务表格，逐处确认引入位置。保留原选中、分页、过滤和渲染参数。
- [ ] 运行全量前端回归及修改模块 lint；本机生产构建。独立夹具和正式页面验证拖动、刷新保留、重置及表头排序，检查固定操作列和弹窗表格。
- [ ] 代码复核、提交推送，复用静态热发布流程。核对服务和业务/监控偏好/密钥摘要，更新发布记录与草稿 PR；不重启后端。
