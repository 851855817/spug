# 巡检异常原因可读性修复

用户反馈：运维作业显示“异常”，原因却只有“显示错误：需要关注”，无法判断具体问题。固定 v1 采集器将所有有效告警统一保存为“需要关注”；其中“显示错误”实际是 PHP CLI 的 `display_errors` 配置项名称，并非已发生的 PHP 报错。

## 范围与合同

- 仅调整运维作业结果展示，不修改采集、状态、权限、接口或数据库。
- 对固定 v1 Linux、PHP 和 Web 检查，按已保存的实际值补充具体原因、阈值及简短建议；历史记录无需重新采集。
- PHP 开关显示明确名称与 On／Off，扩展显示加载状态，端口显示监听状态，资源百分比带单位。
- PHP 原因明确仅代表 CLI 配置；不声称读取了错误日志或验证了网站 PHP-FPM。端口只代表本机监听。
- 未知版本、作业、字段或不符合判定条件的值不套用固定诊断；保留已有具体说明，证据不足时直说未提供判定依据。
