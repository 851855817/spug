# 宝塔版本同步与 SSL 网站状态

**目标：** 纠正外部升级后保留的旧版本；在 SSL 申请/续签的网站选择中显示证书到期日或未配置。

**设计：** 复用任务资源读取已经获得的真实版本，以 API 配置修订号作条件更新版本和检测时间。列表明确时间是上次检测时间，任务标题优先显示本次读取版本；不新增后台全量轮询。网站列表复用官方 getData 已返回的 ssl.notAfter，仅返回经过日期校验的到期日和状态，避免逐网站新增 API 请求。缺失/异常为未知，官方 -1 为未配置，过期独立显示；选中网站使用已有 GetSSL 结果补充精确时间。日期显示采用北京时间。
