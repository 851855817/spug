# 宝塔面板任务计划

入口：**任务计划 → 新建 → 任务内容 → 宝塔面板任务**。

用于在指定时间对固定客户面板执行已配置的宝塔操作。例如每天检查并续签选定网站证书，或在维护时间统一设置防跨站。仍使用「宝塔面板管理」中保存并测试通过的 API，不需要重新填写密钥。

## 创建和启用

1. 填写任务名称和类型，选择「宝塔面板任务」。
2. 选择已有预检，或点「新建宝塔预检」，使用原面板任务表单选择客户、操作和参数。此步骤只查询与生成预检，不执行变更。
3. 核对每台面板的固定目标；按提示勾选证书同步、PHP 重启或文件覆盖等影响确认项。
4. 设置一次性时间、间隔或 Cron，提交保存。新计划默认未激活。
5. 在列表「更多 → 激活任务」确认目标与自动执行方式后启用。

支持面板升级、添加网站、防跨站、伪静态、申请/续签证书、安装软件、PHP 扩展、卸载软件、PHP 更新，以及上传文件或目录。具体可执行操作仍受面板版本、API 和每次预检结果限制。

## 到点怎样运行

每次触发会重新核对执行账号权限和 API 配置，并创建新的面板预检。**全部目标预检通过后才自动开始**，执行后仍需读回核验结果。已经符合目标的项目不会重复变更。

预检失败、账号停用、权限撤销、固定对象身份变化、执行失败或结果待核实时，计划自动停止。查看原因并处理后，可重新配置或启用。系统不会自动重试结果不确定的变更。

计划运行尚未结束时的新触发记为「跳过」，不会并行执行同一计划；间隔至少 300 秒，Cron 的密集触发也会跳过，并保留原因。为防止慢速请求造成连续变更，上次运行结束后还会保留至少 300 秒间隔。错过的时点不补跑。

禁用计划会阻止后续操作。已被 worker 接受的发送意图或已发送的请求可能仍在处理，禁用不会撤销这些请求；需要在关联面板任务查看读回结果。计划停用后仍可对未确认的操作进行只读核验。

## 结果在哪里

**任务计划 → 对应任务 → 详情 / 更多 → 历史记录**：查看成功、失败、跳过、当前阶段，以及逐台原因。

点「查看关联面板任务」展开固定目标、预检信息和具体结果数据。这是只读预览。需要核验或处理结果不确定的子项时，去 **批量执行 → 面板任务 → 执行记录** 打开对应任务。

宝塔计划的「重新预检」只生成预览，不会执行变更；普通 Shell/Python 的「执行测试」保持原有实际执行行为。

配置失败通知后，停止原因会通过原有钉钉、飞书、企业微信或 Webhook 渠道通知。系统先登记发送尝试；通知超时可能已被对方接收，因此不会自动重复发送，请同时查看历史记录。

## 固定范围和权限

- 分组在配置时展开。之后新增的面板或网站不会自动加入计划。
- 网站名称、目录、类型等身份发生变化时停止；证书的域名集合也固定，之后新增别名不会自动申请。
- 软件版本、PHP 分支和预期补丁等参数按创建时填写的目标保存。需要另一个目标版本时，请编辑计划；这不是自动追踪任何新版本的更新器。每次预检仍重新读取已安装版本、资源与依赖条件。
- 修改前须停用计划并结束或核验上次运行；编辑后须重新激活确认。
- 上传源文件在计划存在期间保留，包括未激活状态，持续占用暂存配额；删除计划后按原规则清理。上传计划由源文件所属账号创建和启用。
- 创建须有任务计划新增及面板任务查看、创建权限；启用还须有计划编辑与面板任务执行权限。每次运行和每个发送阶段都会重新检查账号及授权。

示例：给固定网站每天凌晨检查同订单续签，可使用 Cron `0 2 * * *`。证书有效期超过 30 天时原适配器会判定无需续签；到期进入续签条件后才执行。DNS 验证、未适配面板或缺少原订单时预检会阻止操作，不能通过定时计划绕过原来的限制。
