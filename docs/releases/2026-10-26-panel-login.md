## 功能与使用

宝塔面板管理列表的“打开”复用记录中已保存的 API 地址、密钥和证书设置，获取宝塔官方一次性票据并进入宝塔主管理员。无需重复输入账户密码。只有账户密码、未配置 API 的记录仍需先编辑并补充 API；“登录页”保留为手动入口。该功能不代表模拟密码登录或绕过验证码。

超级管理员可用；其他用户必须同时具有查看面板和“一键登录宝塔主管理员”权限，旧角色未自动获权。接口调用前后重新核对实际权限、会话及面板配置；只接受记录 ID、严格官方票据和保存地址下的登录路径。票据不入库、不记录日志，响应禁止缓存；浏览器新页无 opener、无来源信息。官方 Linux 9.2、11.7、13.1 包源码支持该协议，票据约 120 秒有效、使用即失效。详见[使用手册](../spug-platform-user-manual.md)和[规格](../superpowers/specs/2026-10-26-panel-login-design.md)。
