## 原因和修正

两台真实主机使用 Python 3.6.8。该版本 shlex 在 whitespace_split 模式下未拆分 `epoll;` 等标点，旧探针尚未展开网站引用就误报配置语法异常。改用兼容 Python 3.6 的有限分词器，明确区分结构分隔符和字符串文字。

继续只读验证时发现宝塔 well-known 配置内有 set_by_lua_block。探针现在仅跳过白名单内非 SSL Lua 块的代码文本，处理其中字符串和注释，不执行 Lua，不把其中 include 文本当作配置。整个 Web 服务继续禁止自动重载；动态 SSL Lua、转义证书路径、越界引用等仍拒绝。

两台来源均保留“部分配置覆盖不足”提示：默认站点、正则或动态域名不能作为确定域名发起 TLS 握手。上述 9 条具体域名的证书已正常读取。自动续签是否支持仍由原有部署、客户端和服务预检决定，本次未执行续签、安装、配置改写或重载。
