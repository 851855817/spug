# 到期管理与站内提醒发布记录

2026-10-25（Asia/Shanghai）发布到现有演示实例。应用提交：`5e6f50da476ea993273981366ed160e4cfb675bd`，分支 `feature/operations-reliability`，沿用草稿 [PR #4](https://github.com/851855817/spug/pull/4)，未合并主分支。

## 本次功能

- 主机管理页右上角增加“到期管理”，路由 `/host/expiry`，仅活跃超级管理员可访问。
- 汇总 SSH 主机和宝塔，复用已有人工确认的关联；关闭监控也可管理。人工日期独立保存，云导入不覆盖，展示负责人、跟进、备注和续费审计。
- 提醒默认关闭，每日 09:00 复用现有 scheduler 检查本地数据库，不连接客户服务器，不发送外部消息。
- 同一资产／日期／阶段持久去重，管理员个人已读独立保存。续费、关联变化后的旧提醒保留并可识别为过时。
- 新增六张附加表，保持原模型、库存、租约和运维记录。

使用方法见[到期管理指南](../server-expiry-guide.md)，总手册已添加入口。
