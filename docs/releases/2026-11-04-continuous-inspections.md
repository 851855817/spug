# 连续主机巡检发布记录

## 行为

入口：批量执行 → 面板任务 → 主机巡检。新建巡检移除“每批台数”和“批内失败熔断阈值”；点击“确认执行”直接创建并逐台检查全部目标，不再二次弹窗。单台失败、超时或待核实保留具体原因及处理建议，并继续下一台。最多 50 台，可取消尚未执行项。运行中断不重发已下发目标，连续任务继续剩余项；历史手动批次作业按原规则处理。

只调整巡检的 service、worker、runner 三个既有 API 文件与 RunForm、RunDetail 两处界面。没有模型、数据库迁移或权限范围变更；宝塔升级、安装、证书等变更任务保留既有流程。
