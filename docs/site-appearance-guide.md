# 全站配色模板

入口：**系统管理 → 系统设置 → 外观配色**。由活跃的超级管理员统一设置，所有账号使用相同配色。

## 选择与应用

1. 在“商务精选”或“经典配色”中选择模板。卡片上的后台缩略图展示各模板的导航、表面和强调色。
2. 查看下方示例中的导航、按钮、监控卡片、任务表格和状态标签。选择本身只改变示例。
3. 点击 **应用全站**。保存成功后当前页面立即更新；其他已打开且可见的页面在一分钟内同步，重新打开页面也会读取统一设置。

**恢复经典蓝**需要确认，确认后同样对所有账号生效。**取消选择**仅放弃当前未保存选择。

| 模板 | 适合的场景 |
| --- | --- |
| 经典蓝 | 默认运维后台，清晰明快 |
| 青碧 | 柔和青绿，长时间日常浏览 |
| 靛紫 | 突出按钮和选中项 |
| 石墨灰 | 低饱和，突出运维数据 |
| 深色夜间 | 夜间值班，减少大面积亮色 |
| 曜石金 | 炭黑与哑光香槟金，适合沉稳的深色工作台 |
| 深海青 | 深海蓝灰与雾青，适合长时间值班 |
| 月影紫 | 墨紫灰与柔和月光紫，适合低亮度环境 |
| 暖瓷白 | 温润瓷白与摩卡棕，适合明亮的办公环境 |
| 雾松绿 | 雾白与低饱和松绿，适合日常运维 |
| 香槟砂 | 浅砂岩与古铜金，适合商务展示 |

正常、告警、异常继续使用绿色、橙色、红色及状态文字。终端与代码编辑器的内容区沿用专用配色；外部页面随全站切换。

## 保存或同步失败

- 保存失败：保留当前配色和已选模板，按错误提示重试。
- 其他管理员先保存：当前草稿不会被后台同步覆盖；点击 **重新载入**读取最新设置后重新选择。
- 暂时断网：保留上次配色；首次无法读取时使用经典蓝，不影响登录或其他功能。

配色设置不连接客户服务器，不产生运维任务，也不会开启监控或提醒。普通员工和岗位角色不能通过外观接口修改全站配色。
