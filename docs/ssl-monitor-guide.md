# SSL 监控

入口：**监控中心 → SSL 监控**。管理员在一个页面查看宝塔和 SSH 主机的网站证书，发现临期、过期、未配置和检查异常，并对支持的证书发起续签。

## 首次使用

1. 在“来源设置”选择已添加的宝塔或 SSH 主机，开启 SSL 检查。SSL 开关与服务器 CPU、内存监控开关独立，默认均不代替用户开启。
2. 按需开启到期提醒。默认每 6 小时检查一次，也可选 1、12、24 小时。
3. 点击检查，等待后台任务结束。页面刷新只读取已有结果，不会反复连接服务器。
4. 点击上方统计卡可筛选正常、10 天内到期、已过期或异常证书；通过来源、域名进一步查找。

开启者账号失去权限或来源配置变化后，会停止后续连接。管理员可在来源设置中点击对应行“重新授权”，再保存配置；其他正常来源不会因此被重新配置。

宝塔来源需要已保存有效 API 信息。SSH 来源使用主机管理中的已验证 SSH 连接，目标服务器须有 Python 3。功能当前仅对活跃超级管理员开放，不自动给原有岗位增加权限。

### 仅通过 SSH 巡检

在“主机管理”添加服务器并验证 SSH 连接，然后进入“监控中心 → SSL 监控 → 来源设置”，开启该 SSH 主机的“启用巡检”，按需开启“到期提醒”，保存后点击“立即巡检”。不需要宝塔 API，也不需要先安装 acme.sh／Certbot；这些工具只在复用现有订单续签时需要。

主机需提供 Python 3，SSH 账号能够读取 Web 配置及配置引用的公开证书。自动发现目前覆盖 `/etc/nginx/nginx.conf`、`/www/server/nginx/conf/nginx.conf`、`/etc/apache2/apache2.conf`、`/etc/httpd/conf/httpd.conf`、`/www/server/apache/conf/httpd.conf` 及受支持目录内的引用。没有标准主配置时可读取固定宝塔 vhost 目录，但不据此开放续签。自定义主配置、容器内配置或其他 Web 服务暂不自动发现。

SSH 探针兼容 Python 3.6，服务器无需为此升级 Python。宝塔域名验证配置中常见的非 SSL 内联 Lua 块可跳过代码内容后继续发现证书；不会执行 Lua，也不会把其中的文本当成配置引用。这类来源仍不开放自动服务重载；动态证书选择或无法完整识别的 Lua 配置继续拒绝。

普通 Nginx location 正则的 `$` 结束锚点可以识别；动态证书路径、未知证书选择和范围外配置引用仍会拒绝，不把未完整识别的结果计为成功。失败时查看任务结果及来源状态中的固定原因与处理方向，例如“引用文件不存在”“无法读取”“引用循环”或“读取超限”。首次巡检失败会保留该原因，不再因没有成功快照而显示“来源配置已变化”。旧任务的笼统错误无法还原，新巡检才会记录具体原因。

同一服务器同时登记 SSH 和宝塔时是两种独立来源；可按实际需求选择来源，避免重复采集。来源开关不等于服务器 CPU／内存监控开关。

## 如何看结果

| 信息 | 含义与例子 |
| --- | --- |
| 本地证书 | Web 服务配置引用的证书。例如 Nginx 使用的 fullchain.pem。 |
| 公网证书 | 用户访问域名时，通过 SNI TLS 握手实际得到的证书。 |
| 两者不同 | 可能经过 CDN、负载均衡或使用了另一个入口。需要分别处理，更新源站不代表 CDN 证书已更新。 |
| 未配置 | 发现域名，但没有可解析的部署证书。不会计入正常。 |
| 检查失败 | 网络、证书验证、权限或配置解析有问题，详情中显示原因。 |
| 数据已旧 | 上次检查失败或已超时。保留历史日期供参考，不能作为当前正常的依据。 |

时间按 UTC+8 显示，以实际到期时刻判断，不按日历日期取整。过期、自签名、域名不匹配等情况会明确标记；能建立 TLS 连接不等于证书可信。

自动发现覆盖受支持的宝塔网站及常见 Nginx／Apache 配置，不会扫描整个磁盘。动态生成配置、容器内部配置、未知 Web 服务或超出读取限额会报告覆盖不足。配置中的通配符域名可以显示本地证书，不能直接作为公网握手地址。公网握手不访问私有或特殊 IP，不抓取网页内容。

宝塔标准网站常有 include 配置引用。无法只通过 API 穷尽这些引用时，会尝试向面板登记的公网服务器发起域名 SNI 握手，核对源站实际证书与面板副本；匹配后可用于到期监控，但不表示已证明所有配置引用和部署路径。源站无法连接或副本不一致时明确显示待核实。公网域名检测仍独立进行，CDN 不会替代源站检查。

## 隐藏不再关注的过期证书

在过期证书行点击“隐藏”，该记录会从本人默认证书列表和统计中移除。勾选列表筛选区“查看已隐藏”可查看隐藏项，点击“恢复显示”可撤销；同一域名在不同服务器上可分别处理。设置保存到当前账号，刷新、重新登录和换浏览器后保持，其他账号不受影响。

隐藏只针对当前证书指纹和到期时间；后续巡检发现换证会自动显示。“隐藏”不删除证书和任务，不关闭巡检，也不改变“不再提醒”设置。需要关闭提醒时请另外点击提醒列的“不再提醒”。隐藏视图也可以使用域名、分组、服务器和状态筛选。

## 一键续签

点击续签先创建只读预检。预检通过后，核对来源、域名、现有客户端、验证方式、部署位置和服务重载影响，勾选确认项后才执行。

不准备执行时点击“放弃预检”，释放该服务器的续签占位。只读预检超过 30 分钟会自动失效；已经发送或结果待核实的续签不能用此方式取消和重发。

- **宝塔：** 复用既有“续签 SSL”面板任务。若面板 API 可能同步其他网站或面板证书，确认页会要求明确确认影响。
- **仅 SSH：** 复用服务器已存在的 acme.sh 或 Certbot 订单。只有能唯一对应当前网站、验证和部署方式可确定的订单才允许执行。
- **没有客户端或配置不支持：** 查看官方安装配置指导，完成配置后重新检测。此入口不会静默安装软件，也不会改写现有验证方式。

不会全量执行 ACME cron，不会强制续签，不接受前端提交任意命令。未知自定义 hook、动态命令、订单对应不唯一等情况会阻止执行并给出原因。DNS 验证只复用现有已配置订单，不要求把 DNS 密钥填写到浏览器。

acme.sh 订单可识别的既有重载命令仅限已验证 Nginx 绝对路径的配置检查加重载，例如 `/usr/sbin/nginx -t && /usr/sbin/nginx -s reload`。指定独立主配置时，两段命令都须使用相同、已识别的 `-c` 路径。service／systemctl 及其他自定义 hook 暂不接管；不要为通过检查删除既有自动续签配置，请继续使用原机制或人工处理。

宝塔网站的配置引用未完整核实时，不从监控页直接续签；“配置指导”提供进入既有宝塔续签任务的入口，核对该任务的预检和影响后处理。通配符记录不能直接发起续签，请从使用同一证书的具体域名条目发起；不会对 `*.example.com` 发送公网握手。

任务结束会检查证书部署和公网生效情况。连接中断或超时可能表示远程操作已发生，此时显示待核实，先使用只读核验，不自动重试续签。同一服务器的续签会串行处理。

只读核验确认本地证书已更新、到期时间延长，且公网已使用该新证书时，可显示“证书已核实”并释放服务器占用；如果原服务重载回执丢失，会继续明确显示“重载尚未核实”，不冒充已确认重载过程。

## 到期提醒

开启后在 30、10、7、3、1 天及已过期阶段提醒。提醒来自有效检查结果，不用旧缓存伪造最新到期状态。

“不再提醒”只影响当前账号，其他管理员仍可查看；可恢复提醒。证书指纹或到期时间更新后按新周期提醒。SSL 页面、首页及顶栏提供入口，不向所有账号广播客户域名。

证书列表的“提醒”列也可直接点击“不再提醒”或“恢复提醒”，与上方到期提醒区同步。忽略后仍保留证书、状态和统计；只是当前账号不再收到这张证书本周期的到期提醒。“未开启提醒”表示来源尚未开启提醒，“暂无到期提醒”表示当前没有有效到期提醒，按钮不会自动打开任何来源开关。

本版提供站内提醒和确认后续签。无人确认自动续签及外部消息渠道不属于此功能；已配置的宝塔定时任务仍按其独立规则运行。
