# 岗位权限模板

入口：**系统管理 → 角色管理 → 功能权限 → 岗位模板**。先新建角色或选择已有角色，选择岗位后查看说明、完整权限清单和高风险权限，点击 **套用到当前草稿**，核对勾选项后保存。套用会替换当前功能权限草稿；取消不会写入角色。保存后，关联员工需要重新登录。

| 模板 | 主要用途 | 权限边界 |
| --- | --- | --- |
| 只读审计 | 查看主机、面板、任务、发布、监控及报警记录 | 只查看，不含终端和命令 |
| 值班运维 | 排障值班，在授权主机使用终端和执行命令，取消未下发面板项目 | SSH 可修改主机；不含面板执行和宝塔免登录 |
| 网站运维 | 查看宝塔与面板任务，创建预检和取消未下发项目 | 执行权限目前同时覆盖升级、安装、卸载，所以默认只预检，由主管执行 |
| 发布工程师 | 构建版本、提交并执行发布、运行既有流水线 | 不含发布审核；流水线可能执行预设远程动作 |
| 运维主管 | 维护主机和面板、批量执行及分发、面板执行与人工判定、审核发布 | 含宝塔主管理员免登录等高风险功能；不是平台超级管理员 |

功能权限与资源范围独立：请在 **主机权限** 分配可访问 SSH 主机组，在 **发布权限** 分配应用和环境，再把角色关联到员工账号。模板不自动关联员工，也不授予超级管理员身份。多个角色的权限会合并，叠加角色时需同时核对。

当前宝塔权限覆盖全部面板，不按 SSH 主机组隔离；网站与证书、运维作业、到期管理等现有超级管理员专用页面仍保持限制。需要按客户隔离或只允许某种面板变更时，须另做细分权限，不能依赖岗位名称实现隔离。
